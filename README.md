# 数学ワークサポート（方程式・比例と反比例）

中1数学 2学期期末テストの範囲（3章 方程式：ワーク p.62〜77、4章 比例と反比例：ワーク p.78〜99）を、ステージ順に進めて自分で解き切るためのアプリです。
「方程式ワークサポート」と「比例と反比例ワークサポート」を1つにまとめました。

## 画面
- **苦手をつぶす**（いちばん上）：記録からわかった苦手を、ひびの入ったブロックで表示。「直す」を押すと、毎回ちがう数の問題が出る
  - 1回でまちがえずに解けるとブロックが1つ直る。スプレッドシートの「まだ直っていない」と同じ決まりで、必要な回数（×が1回なら1回、2回以上なら2回続けて）正解すると「卒業」
  - 最初に、その苦手の「いい例・悪い例」とまちがい探しを確認してから問題に入る
- **章のタブ**：3章 方程式 / 4章 比例と反比例。章ごとに「次はここ」とステージの順番が出る
- **ステージ**：① ポイント → ② さわって解く → ③ 紙でやる（ワークのページ）。最後にボス

## 記録（Google スプレッドシート「拓真 数学まちがい記録」）
平面図形のアプリと同じ送り先・同じ合言葉を使う（この端末に保存されている設定をそのまま使う）。

- ステージの1問ごと、苦手トレーニングの1問ごとに ○ / × を送る（1回でまちがえずに解けたら ○、途中でまちがえたら ×）。電波がないときは端末にためて、あとで送る
- 単元は「方程式」「比例と反比例」、失点パターンは練習の種類（移項、比例の式（x と y・符号）など）で記録
- スプレッドシートの「まだ直っていない」問題を読みこみ、「苦手をつぶす」に出す。前に記録したワークのまちがい（hirei-○○、eq-○○ など）も、練習の種類に分けて出る
- 設定がない端末では、この端末でのまちがいだけで「苦手をつぶす」を出す。設定はホーム画面のいちばん下「記録の送り先（おうちの人用）」

## 前のアプリからの引きつぎ
同じサイト（同じ GitHub アカウントの Pages）に置くと、「方程式ワークサポート」「比例と反比例ワークサポート」の進み具合と、記録の送り先の設定をそのまま引きつぐ。

## 公開（GitHub Pages）
1. このフォルダの中身（index.html / icon.png / .nojekyll / README.md）を、平面図形のアプリと同じ GitHub アカウントのリポジトリのルートに置く
2. Settings → Pages → Branch: main / root を選んで保存

問題はワークと同じ型で、数を変えてあります（ワークの問題そのものは入れていません）。端末で「動きを減らす」を設定している場合はアニメーションが止まります。
